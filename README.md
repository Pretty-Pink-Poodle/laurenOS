# 💿 laurenOS

**laurenOS** is an interactive retro desktop portfolio built with HTML, CSS, and JavaScript.

Instead of using a traditional scrolling portfolio layout, laurenOS presents my work, technical experience, certifications, resume, and contact information through a browser-based faux operating system inspired by late-90s / early-2000s desktop interfaces.

🌐 **Live Demo:**  
https://pretty-pink-poodle.github.io/laurenOS/

---

## ✨ Features

- Draggable desktop windows
- Window minimize, restore, and close controls
- Dynamic taskbar buttons
- Active window / z-index management
- Start menu navigation
- Persistent desktop themes using `localStorage`
- Pink Dream, Office Blue, and Night Mode themes
- Interactive Project Explorer
- Employment Records experience viewer
- Credential Manager for certifications
- Resume Viewer with view and download options
- Contact app with email copy functionality
- Notification center and desktop toast messages
- Functional command-line terminal
- Music player with playlist, playback controls, progress, and volume
- Animated boot screen
- About laurenOS system information window
- Responsive layouts for smaller screens

## 🖥️ Portfolio Sections

### About Me
A short introduction and overview of my background.

### My Computer
Displays technical skills across programming, web development, development tools, and IT support.

### Project Explorer
Interactive project browser featuring:

- **TicketFlow** — IT Service Desk Dashboard
- **Y2K Weather App** — REST API weather application
- **laurenOS** — Retro Desktop Portfolio

### Experience
Professional experience across IT support, help desk operations, customer support, and education.

### Certifications
Credential manager displaying certifications from:

- Microsoft
- CompTIA
- ISC2

### Resume
Includes a recruiter-friendly resume preview along with options to view or download the full PDF.

### Contact
Provides email, GitHub, location, availability status, and a copy-email function.

### About laurenOS
Displays system information, build details, technologies used, education path, and project information.
