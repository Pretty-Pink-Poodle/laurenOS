# 💿 laurenOS

**laurenOS** is an interactive retro desktop portfolio built with HTML, CSS, and JavaScript.

Instead of using a traditional scrolling portfolio layout, laurenOS presents my projects, technical experience, certifications, resume, contact information, and skills through a browser-based faux operating system inspired by late-90s and early-2000s desktop interfaces.

🌐 **Live Portfolio:**  
https://pretty-pink-poodle.github.io/laurenOS/

💻 **Repository:**  
https://github.com/Pretty-Pink-Poodle/laurenOS

---

## ✨ About the Project

laurenOS was designed as both a personal portfolio and a software development project.

The goal was to create something more interactive than a traditional portfolio website while still making my professional background easy for recruiters and hiring managers to explore.

The interface functions like a miniature desktop operating system, with draggable windows, a taskbar, Start menu, themes, notifications, applications, a terminal, and persistent browser preferences.

It combines my background in IT support with my growing software development skills while giving me room to build something functional, interactive, and visually personal.

## 🧠 What I Learned

Building laurenOS gave me experience treating a website as a connected application rather than a collection of isolated pages.

Through this project, I practiced:

- Designing a desktop-style user interface
- Building reusable window behavior
- Managing application state
- Working with DOM events
- Creating dynamic taskbar behavior
- Managing z-index and active-window states
- Implementing minimize and restore functionality
- Persisting user preferences with `localStorage`
- Dynamically rendering project information
- Building terminal command logic
- Managing browser audio playback
- Creating notification systems
- Building interactive controls
- Designing responsive layouts
- Debugging regressions while adding features
- Maintaining multiple interconnected components
- Working with Git and GitHub
- Deploying a static web application with GitHub Pages

One of the biggest challenges was continuing to expand the project without breaking functionality that had already been implemented.

That made laurenOS a useful exercise in both development and debugging.

## 🚀 Run laurenOS Locally

Clone the repository:

```bash
git clone https://github.com/Pretty-Pink-Poodle/laurenOS.git
```

Move into the project directory:

```bash
cd laurenOS
```

Then open:

```text
index.html
```

in your browser.

No frameworks, dependencies, package managers, or installation steps are required.
